## 方針転換(2026-08-19 確定): ストア配布はやらない

Google Play・App Store への配布を**両方とも取りやめる**。理由は個人開発者の住所公開:

- **Google Play**: 個人アカウントで収益化(有料アプリ・アプリ内購入・広告)すると、完全な物理住所がストアの掲載情報に公開される。無料かつ収益化なしなら公開されるのは本名・国・メールアドレスまでで住所は出ないが、収益化した瞬間に住所が出る。回避するには組織アカウント(法人登記+D-U-N-S 番号)が要る。
- **App Store**: 個人開発者は本名が公開される。加えて日本では有料販売時に特定商取引法で住所・電話番号の表示義務が生じる。$99/年も要る。

住所を出さずに収益化する道がストア側に無いため、**収益化は Web/PWA 上の「低コスト・住所非公開」な手段に一本化する**(Ko-fi の Tip、AdSense 等)。この判断により Phase 1 の Android 部分と Phase 3(iOS)は破棄され、以下の作業がすべて不要になった。

- Google Play 開発者登録($25)・クローズドテスト(12 人×14 日)・Play Console 操作
- TWA パッケージング(Bubblewrap・`twa/twa-manifest.json`・署名鍵の保管)
- `Uni-K-Pip/uni-k-pip.github.io` の新規作成と `.well-known/assetlinks.json`
- ストア掲載素材(説明文 4 言語・スクリーンショット・フィーチャーグラフィック)
- iOS の Capacitor 化

以降の各節に残るストア関連の記述は、**撤退の判断根拠と経緯の記録**として残す。実施対象ではない。

## 前提(2026-08 時点の調査結果)

### 撤退の判断根拠: 個人開発者の住所公開(2026-08-19 調査)

- **Google Play**: 個人(individual)アカウントは、有料アプリ・アプリ内購入・広告のいずれかで収益化すると、ストアの掲載情報に完全な物理住所が公開される。無料かつ収益化なしのアプリなら公開項目は本名・国・メールアドレスに留まり住所は出ないが、収益化した時点で住所が出る。住所を出さずに収益化するには組織(organization)アカウントが必要で、それには法人登記と D-U-N-S 番号が要る。
- **App Store**: 個人開発者は本名がストアに公開される。日本で有料販売する場合は特定商取引法により住所・電話番号の表示義務が生じる。開発者登録は $99/年。
- 本アプリは個人開発かつ収益規模も小さいため、法人化のコストは釣り合わない。→ ストア配布を両方とも取りやめ、Web/PWA 上の手段に絞る。

### ストア配布の方式(記録。実施しない)

- **Google Play**: PWA を TWA(Trusted Web Activity)で包むのが Google 公式サポートの方法。Bubblewrap CLI か PWABuilder で APK/AAB を生成し、Digital Asset Links でサイト所有権を検証する。アプリ本体は GitHub Pages 配信のままにできる。
- **App Store**: TWA 相当の仕組みが無く、Capacitor(または Cordova)でのラップが必須。Web 技術ラップだけのアプリは Guideline 4.2(minimum functionality)でリジェクトされるリスクがある。
- **開発者登録費用**: Google Play は $25(買い切り)、Apple は $99/年。
- **Google Play の個人アカウント要件**: 2023-11-13 以降に作成した個人アカウントは、本番公開の前に「12 人のテスターが 14 日間連続でオプトイン+インストール済み」のクローズドテストが必須(2024-12-11 に 20 人から 12 人へ緩和)。

### 手数料と日本のスマホ新法(記録。ストア撤退により当面は関係しない)

- 日本のスマホソフトウェア競争促進法(MSCA)が 2025-12-18 に施行され、日本では外部課金リンクが解禁、代替ストアも許可された。
- Apple(日本): IAP 手数料は 15〜26%(基本 21%+決済 5%。Small Business Program 対象なら 10%+5%=15%)。外部リンク経由は 15%(SBP なら 10%)。
- Google(日本): 手数料を 20% へ引き下げ、外部決済も許可。
- 手数料は情報源間で数字が食い違い、MSCA 施行後の運用も流動的。ストアに戻る判断をするなら、そのときに再調査する。

### Web での収益化手段(Phase 2 の候補)

- **Ko-fi の Tip / Membership**: 寄付は手数料 0%。受け取りは PayPal / Stripe。住所の公開は不要。実装は外部リンクのみ。
- **Google AdSense**: Web サイトへの広告掲載。住所は登録時に必要だが**公開はされない**(PIN 郵送での住所確認はあるが掲載情報には出ない)。審査があり、PWA のようなアプリ的サイトは有用性の評価が読めない。収益は月数百円オーダーの見込み。
- **AdMob(アプリ内広告)**: ストアアプリ向けなので撤退により対象外。
- ~~いずれも Phase 2 で判断する。広告は UX を悪化させるため、寄付の反応を見てから決める。~~
- **2026-08-20 に決着: AdSense は却下。** 審査の見込み・`github.io` の親ドメイン承認・`ads.txt` の設置場所・収益見込みの 4 点で不可と判断した。詳細は `docs/design/2026-08-20-analytics-design.md`。

## リスク

- **収益の期待値は低い**: 寄付はほぼゼロ、Web 広告も月数百円オーダー。「収益化の仕組みを一通り経験する」ことを主目的と割り切る。
- **配布リーチが小さい**: ストアに出さないので発見経路が Web 検索と口コミに限られる。ダウンロード数の伸びは期待できない。
- ~~**AdSense の審査**(Phase 2): PWA のようなアプリ的サイトはコンテンツ量の評価が読めず、審査に通らない可能性がある。~~ → 2026-08-20 に、この懸念が現実的であることを実例で確認し、AdSense 自体を却下した。
- **Web 決済と特商法**(Phase 2 で有料化する場合): 日本で有料販売するなら住所・電話番号の表示義務が生じる。ストアを避けた理由と同じ問題が Web でも起きるため、有料化は慎重に判断する。
