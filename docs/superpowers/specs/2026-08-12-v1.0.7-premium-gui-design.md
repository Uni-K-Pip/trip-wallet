# v1.0.7 設計: GUI のプレミアム化

日付: 2026-08-12(概要)/ 2026-08-13(詳細化・確定)
対象バージョン: 1.0.7
位置づけ: 確定スペック。ビジュアル方向は Visual Companion でのモック比較により、設計詳細はセクション単位のレビューにより、すべてユーザー承認済み。

## 目的

アイコンと全体の GUI を「高価な」見た目に引き上げる。v1.0.8 以降のストア配布(審査・ストア掲載画像・他アプリとの比較)に耐える品質にすることが狙い。機能は変えない。あわせて既知の UI 不具合 2 件(集計タブの平均ラベル被り・エクスポート促しバナーの設定タブ表記)を修正する。

## 確定した方向性(モック比較の結果)

- **配色: 案 B「Indigo × Violet 全面刷新」**。slate × sky から indigo × violet へ色相を変える。
- **アイコン: 案 3「SVG 磨き込み」**。現行構図のまま紫グラデーション+光沢+グローを追加。ベクター維持で `npm run icons` パイプラインをそのまま使う。gpt-image-2 生成案(3D / ソフトフラット)は比較の結果不採用。
- **アニメーション: 案 C「リッチ」**(200–400ms +カウントアップ・スライドインジケーター・FAB 呼吸グローの常時演出)。
- **ライトテーマは追加しない**(ダークのみ維持)。
- **ストア掲載用スクリーンショットは v1.0.8 に回す**。
- **Web フォントは入れない**。システムフォントスタック維持、数字は `font-variant-numeric: tabular-nums`。
- **新規依存ライブラリはゼロ**。CSS +素の JS(requestAnimationFrame)のみで実現する。

## 2. 質感の適用方針

**すりガラス(`backdrop-filter: blur(14px)` + `--glass` + `--glass-border`)は少数の「常時見えている面」だけ**に絞る:

- 合計カード(ホーム・集計)— さらに `rgba(129,140,248,0.18)` のグラデーションを重ねる
- タブバー
- モーダル / シートのパネル(オーバーレイは `rgba(12,10,29,0.6)` の暗幕のみ。オーバーレイ自体はぼかさない)
- ヘッダー(sticky である場合のみ。実装時に確認)

**スクロールで量産される行にはグラスを使わない**(性能対策)。支出行・設定行・カテゴリ行は「半透明 surface + 1px 縁(`--glass-border` 系)+軽いシャドウ」。バナーも同様+アクセント縁。

その他:

- `--grad-accent` の適用先: FAB、primary ボタン、予算バー、グラフのバー
- セグメントコントロール(集計のビュー切替)はスライドインジケーター方式に変更
- フォーカスリングは `--accent`
- 本文テキストは WCAG AA(4.5:1)を維持。すりガラス上の文字は特に注意

## 3. マイクロアニメーション仕様

| 対象 | 内容 | 時間 / イージング |
|---|---|---|
| タブ切替 | フェード+ 8px 上昇(マウント時 animation) | `--dur-base` / `--ease-swift` |
| リスト入場 | 行ごとに 70ms ずらすスタッガー。**遅延は先頭 8 行で頭打ち**(9 行目以降は同時) | `--dur-base` / `--ease-swift` |
| モーダル / シート | 出現 280ms、閉じ 180ms | `--ease-swift` |
| 予算バー / グラフのバー伸長 | 伸長アニメ。集計のセグメント切替時は `key={view}` で再マウントして再生 | `--dur-slow` / `--ease-swift` |
| 金額カウントアップ | JS(requestAnimationFrame)500ms。対象はホーム合計と集計合計。初回は 0→値、値変更時は前回値→新値。`useCountUp` フックとして切り出す | 500ms / ease-out(三乗) |
| 日別グラフの平均線 | フェードのみ | `--dur-base` |
| FAB | 呼吸グロー(box-shadow 明滅、3.6s 無限ループ)+押下 scale(0.96) | 3.6s / ease-in-out |
| ボタン押下 | scale(0.96) | `--dur-fast` |
| セグメントインジケーター | translateX スライド | `--dur-base` / `--ease-swift` |

**reduced-motion**: `@media (prefers-reduced-motion: reduce)` で全 animation / transition を無効化。JS 側(`useCountUp` 等)も `matchMedia` で検知して即座に最終値を表示する。

## 5. UI 修正 2 件

### 修正 1: 集計タブの平均ラベル被り(`src/ui/DailyChart.tsx`)

現象: 赤(ピンク)文字の平均ラベルは平均線の上(`top: -14px`)に出るため、平均が最大値に近いとチャート上端をはみ出し、上部のビュー名(自己負担 / 個人 / 共有)と被る。

対応: 平均線の位置がチャート上端に近く、ラベル高さ 14px が収まらない場合、ラベル `span` に修飾クラス(例 `daily-avg--below`)を付与して線の**下**に表示する。チャートの高さ・平均線自体の位置は変えない。判定はコンポーネント内の単純な条件分岐+ CSS 1 ルール。

### 修正 2: エクスポート促しバナーの設定タブ表記(`src/app/App.tsx`)

現象: 旅行終了後のバナーが設定タブでも「設定から〜」という文言と「設定へ」ボタンを表示する(すでに設定タブにいるのに)。

対応: `tab === 'settings'` のとき、文言を新 i18n キー `app.exportReminderSettings`(ja: 「旅行が終わりました。下の『バックアップを書き出す』からデータを書き出しておきましょう。」)に切り替え、「設定へ」ボタンを非表示にする(「閉じる」は残す)。新キーは 4 言語(ja / en / ko / zh)すべてに追加する。

## 制約

- PWA の軽さを維持する: バンドルサイズの大きな増加(アニメーションライブラリ・Web フォント)は入れない。CSS 中心で実現する。
- オフライン動作・既存機能の回帰なし(既存テスト全通過を維持)。
- テキストコントラストは WCAG AA 相当を保つ(すりガラスの上の文字は特に注意)。
- `prefers-reduced-motion: reduce` でアニメーションを無効化する(CSS・JS 両方)。

## リスク

- **`backdrop-filter` の性能**: 低スペック Android 端末で描画が重くなりうる。適用範囲を「常時見えている少数の面」(合計カード・タブバー・モーダル/シート・ヘッダー)に絞り、スクロールで量産される行には使わない。実機で確認する。
- **リッチアニメーションのくどさ**: 毎日使うアプリで演出過多になるリスク。遷移系の時間は最長 420ms(カウントアップのみ 500ms)に抑え、スタッガーは 8 行で頭打ちにする。常時演出は FAB の呼吸グローのみ。実機確認で気になれば弱める。
- **紫背景でのコントラスト**: `--text-dim: #8b87ad` など中間色は AA を下回りやすい。実装時にコントラスト比を確認し、必要なら明度を上げる。
