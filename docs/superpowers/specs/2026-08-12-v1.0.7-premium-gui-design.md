# v1.0.7 概要設計: GUI のプレミアム化

日付: 2026-08-12
対象バージョン: 1.0.7
位置づけ: 概要スペック。方向性と枠だけをここで確定し、具体的なビジュアル(配色・アニメーション・アイコン最終案)は v1.0.7 着手時の brainstorming でモックを見比べて決める。

## 目的

アイコンと全体の GUI を「高価な」見た目に引き上げる。v1.0.8 以降のストア配布(審査・ストア掲載画像・他アプリとの比較)に耐える品質にすることが狙い。機能は変えない。

## 決定事項(この文書で確定)

- **方向性はモダンプレミアム**: すりガラス感・繊細なグラデーション・マイクロアニメーション。近年の金融系・旅行系アプリの「高そうな」文法に寄せる。ラグジュアリー(黒金)や旅行モチーフ路線は採らない。
- **画像生成は gpt-image-2($imagegen)を優先**(グローバルルールどおり)。Codex 経由で使えなければ OpenAI Images API 経由。
- **Web フォントは原則入れない**: システムフォントスタックを維持し、PWA の軽さとオフライン初期表示を守る。数字の見栄えは `font-variant-numeric: tabular-nums` 等 CSS で工夫する。

## 現状の足場

- `src/styles.css` は約 780 行の単一ファイル。既にダーク基調の単一テーマで、`:root` の CSS 変数(`--bg: #0f172a` / `--surface` / `--text` / `--text-dim` / `--accent: #38bdf8` / `--danger` / `--ok` / `--radius: 14px`)に集約済み。slate × sky 系の落ち着いた配色。
- アプリアイコンは `public/icon.svg` を編集して `npm run icons`(sharp)で各サイズの PNG を生成する仕組みが整っている。
- vite-plugin-pwa がマニフェストを生成。ライトテーマは無い。

土台が整っているため、**作り直しではなく磨き込み**で進められる。

## やること(候補)

1. **デザイントークンの拡充**: 色の階調(surface 2〜3 段)・影 3 段(カード / シート / 浮遊要素)・グラデーション・トランジション速度を CSS 変数として整備し、全コンポーネントで参照する。
2. **アプリアイコンの刷新**: gpt-image-2 で候補を複数生成し、現行 SVG の磨き込み案と見比べて採用を決める。maskable アイコンは現在 `icon-512.png` の流用で宣言だけしている状態(`vite.config.ts`)なので、セーフゾーンを考慮した専用画像に分けることもここで行う。
3. **画面の質感向上**: カード・支出シート・タブバー・ボタンに、すりガラス(`backdrop-filter`)・多層シャドウ・微グラデーションを適用する。
4. **マイクロアニメーション**: シートの開閉・保存フィードバック・タブ切替に短いトランジションを付ける。`prefers-reduced-motion` を尊重する。
5. **グラフの見た目**: 日別推移の棒の角丸・グラデーション、カテゴリ帯の質感、数値のタビュラー数字化。

## 今決めないこと(着手時の brainstorming で決める)

- 具体的な配色・グラデーションの値(現行の slate × sky を深化させるか、色相を変えるか)
- アニメーションの秒数・イージング・対象の絞り込み
- アイコンの最終案(gpt-image-2 生成案 vs SVG 磨き込み案をモックで比較)
- ライトテーマを追加するかどうか(現状ダークのみ。ストア審査・ユーザー層を踏まえて着手時に判断)
- ストア掲載用スクリーンショットの整備(v1.0.8 と分担を調整)

着手時はモック比較が中心になるため、ブラウザでの視覚比較(Visual Companion 等)を前提に進める。

## 制約

- PWA の軽さを維持する: バンドルサイズの大きな増加(重いアニメーションライブラリ・Web フォント)は入れない。CSS 中心で実現する。
- オフライン動作・既存機能の回帰なし(既存テスト全通過を維持)。
- テキストコントラストは WCAG AA 相当を保つ(すりガラスの上の文字は特に注意)。
- `prefers-reduced-motion: reduce` でアニメーションを無効化する。

## リスク

- **`backdrop-filter` の性能**: 低スペック Android 端末で描画が重くなりうる。適用範囲をヘッダー・タブバー・シートに絞り、実機で確認する。
- **「高級感」の主観のブレ**: 言葉で合意しても実物の印象は割れやすい。モック比較で複数案を見てから確定する進め方で吸収する。
- **アイコンのラスター化**: gpt-image-2 案を採用する場合、`icon.svg` → PNG の生成フローが「マスター PNG → リサイズ」に変わる。`scripts/generate-icons.mjs` の改修を伴う。

v1.0.6 リリース後、着手時に brainstorming(モック比較)→ 詳細スペック化 → writing-plans → 実装の通常フローで進める。
