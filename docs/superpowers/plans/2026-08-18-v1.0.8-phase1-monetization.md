# 収益化 Phase 1(アプリ側)実装プラン

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 設定タブに Ko-fi への寄付リンク(サポートセクション)を 4 言語で追加し、TWA(Google Play 版)では非表示にしたうえで、v1.0.8 としてリリースできる状態にする。

**Architecture:** 表示条件を 2 つの小さなモジュールに分ける。`src/app/twa.ts` は「この起動が TWA からか」だけを持ち、初回ナビゲーションの `document.referrer` を localStorage に永続化する。`src/app/donation.ts` は寄付 URL の定数と「サポートセクションを描画してよいか」の判定だけを持つ。`SettingsScreen` は判定関数を呼んで section を出し分ける。localStorage の例外握り潰しは既存 `src/app/settings.ts` から共通ヘルパへ抽出し、2 箇所で同じ try/catch を書かないようにする。

**Tech Stack:** React 19.2 / TypeScript 7.0 / Vite 8.2 / Vitest 4.1 + jsdom 29 / @testing-library/react。検証は `npm run test`(vitest run)と `npm run build`(`tsc --noEmit && vite build`)。

**Spec:** `docs/superpowers/specs/2026-08-12-v1.0.8-monetization-design.md`(「収益化 Phase 1 詳細設計(2026-08-18 確定)」節。とくに「A. アプリ側の設計」「リリースの切り方(確定)」「Phase 1 の検証」)

## Global Constraints

スペックから逐語で引く。全タスクの要件にこれが暗黙に含まれる。

- **寄付 URL の定数**: `src/app/donation.ts` に `DONATION_URL` を 1 箇所で定義する。**空文字のあいだはサポートセクションを描画しない**。これにより Ko-fi アカウントの作成を待たずにコードをマージでき、URL は後から 1 行のコミットで設定できる。
- **設定タブ「サポート」セクション**: `SettingsScreen` のデータセクションの後に追加する。Ko-fi への外部リンク(`target="_blank"` + `rel="noopener noreferrer"`)。文言は 4 言語(ja / en / ko / zh)。
- **TWA 判定**: TWA の初回ナビゲーションでは `document.referrer` が `android-app://<packageId>` になることを検知し、localStorage に永続化する(SPA 内の遷移や再訪で referrer が失われるため)。`display-mode: standalone` は PWA インストールと区別できないため使わない。TWA と判定された環境ではサポートセクションを描画しない。
- **packageId**: `io.github.unikpip.tripwallet`
- テストは jsdom で referrer / localStorage をモックし、表示条件(URL 空・TWA 判定)をユニットテストで固定する。
- **リリースの切り方**: アプリ側の変更 + `package.json` の version を 1.0.8 へ bump + README の「v1.0.8 だけの確認」セクション削除を main へマージ・デプロイした時点で v1.0.8 リリースとする。
- **検証**: コード変更は `npm run test` / `npm run build`。

### このリポジトリ固有の不変条件(壊すと落ちる)

- `src/i18n/ja.ts` が辞書の型の源(`Dictionary = typeof ja`)。**`as const` を付けてはいけない。** ja だけ関数の引数に型注釈を書く。en / ko / zh は `export const en: Dictionary = {...}` なので引数の型注釈は書かない。**4 言語に同じキーを同時に足さないと `tsc --noEmit` が落ちる。**
- localStorage のキーは `trip-wallet:<name>` 形式。
- localStorage はプライベートブラウジングや容量超過で例外を投げる。読み書きに失敗しても起動と操作を止めない。
- テストの描画は `renderWithLang(ui, lang?)`(`src/test/renderWithLang.tsx`)を使う。既定は `'ja'` で、日本語文言でアサーションする。
- 既存の CSS クラス(`.hint` / `.btn-ghost` / `.form-actions`)を流用する。

// プライベートブラウジングや容量超過で localStorage は例外を投げる。
// 設定が読み書きできなくても起動と操作は止めない。
export function readLocal(key: string): string | null {
  try {
    return localStorage.getItem(key);
  } catch {
    return null;
  }
}

export function writeLocal(key: string, value: string): void {
  try {
    localStorage.setItem(key, value);
  } catch {
    // 保存できなくても今回の操作は続行する
  }
}
```

import { findCurrency } from '../domain/currency';
import type { Lang } from '../i18n';
import { readLocal, writeLocal } from './localStore';

const LANG_KEY = 'trip-wallet:lang';
const HOME_CURRENCY_KEY = 'trip-wallet:home-currency';

export function loadLang(): Lang | null {
  const v = readLocal(LANG_KEY);
  return v === 'ja' || v === 'en' || v === 'ko' || v === 'zh' ? v : null;
}

export function saveLang(lang: Lang): void {
  writeLocal(LANG_KEY, lang);
}

/** 新しい旅行の換算先の既定値。対応表にない通貨は保存済みでも捨てる。 */
export function loadHomeCurrency(): string | null {
  const v = readLocal(HOME_CURRENCY_KEY);
  return v !== null && findCurrency(v) !== undefined ? v : null;
}

export function saveHomeCurrency(code: string): void {
  writeLocal(HOME_CURRENCY_KEY, code);
}
```

- [ ] **Step 3: 最小の実装を書く**

`src/app/twa.ts` を新規作成する。

```ts
import { readLocal, writeLocal } from './localStore';

const TWA_KEY = 'trip-wallet:twa';

/** Play 版(TWA)の packageId。TWA からの起動だけ referrer がこの値になる。 */
const TWA_REFERRER = 'android-app://io.github.unikpip.tripwallet';

/**
 * TWA から起動されたことを記録する。
 * referrer が入るのは初回ナビゲーションだけで、SPA 内の遷移や再訪では失われる。
 * そのため起動時に一度だけ判定して localStorage に残す。
 * display-mode: standalone は PWA インストールと区別できないので使わない。
 * 前方一致にすると他の Android アプリから来たリンクを取り違えるので、完全一致で見る。
 */
export function markTwaLaunch(): void {
  const from = document.referrer;
  if (from !== TWA_REFERRER && from !== `${TWA_REFERRER}/`) return;
  writeLocal(TWA_KEY, '1');
}

export function isTwa(): boolean {
  return readLocal(TWA_KEY) === '1';
}
```
