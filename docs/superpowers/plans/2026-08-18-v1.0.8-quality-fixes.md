## Task 1: シート表示中はタブバーと FAB を隠す(不具合 #1)

## Task 2: 日別グラフの平均線を棒より前面に出す(不具合 #2)

**背景:** `.daily-bar` には `animation: grow-up var(--dur-slow) var(--ease-swift) both`(`src/styles.css:935-938`)が付いていて、`fill-mode: both` なのでアニメーション終了後も `transform` が残る。`transform` を持つ要素はスタッキングコンテキストを作り、位置指定レイヤーの実効 `z-index: 0` に描かれる。`.daily-avg` も絶対配置で `z-index: auto` なので同じ層に来る。同じ層では **DOM 順が後のほうが上**に描かれ、現在の JSX は `.daily-avg` が `points.map(...)` より前にあるため、棒が平均線を覆ってしまう。

対処は 2 つ同時に入れる。(a) JSX の並びを入れ替えて `.daily-avg` を棒の後ろに置く — これは jsdom から検証できる。(b) `.daily-avg` に `z-index: 1` を足す — 将来棒側に `z-index` が付いても壊れないようにする保険。

`.daily-avg` は `position: absolute` なので、`display: flex` の `.daily-bars` のフレックスアイテムにはならない。並びを変えても `gap` やカラム幅には影響しない(`.daily-bars` は既に `position: relative`)。

**Interfaces:**
- Consumes: なし
- Produces: `.daily-bars` の最後の子要素が `.daily-avg`(`averageHome > 0` のとき)。Task 3 は同じ `.daily-avg` 要素にカスタムプロパティを足す。

## Task 4: `<g id="motif">` の切り出しを入れ子に耐えるようにする(改善 #4)

**背景:** `scripts/generate-icons.mjs` は `base.match(/<g id="motif">[\s\S]*<\/g>/)` で motif を切り出している。`*` が貪欲なので、`icon.svg` に `<g>` が増えると **最後の** `</g>` まで飲み込む。今の `public/icon.svg` に入れ子 `<g>` が無いので偶然動いているだけ。

単純に `*?` へ非貪欲化しても、motif の中に `<g>` を入れた瞬間に**最初の** `</g>` で切れて壊れる。正しくは開閉の深さを数える。自己終了タグ(`<g ... />`)は開いた扱いにしない。

- [ ] **Step 3: `scripts/svg.mjs` を実装する**

```js
/**
 * SVG 文字列から id 指定の <g> 要素を、対応する </g> までで切り出す。
 * 正規表現の貪欲マッチだと最後の </g> まで飲み込み、非貪欲だと最初の </g> で切れる。
 * どちらも入れ子に耐えないので、開閉の深さを数える。
 *
 * @param {string} svg SVG 全体の文字列
 * @param {string} id 探す <g> の id 属性値
 * @returns {string | null} 見つかった <g>...</g>。無ければ null
 */
export function extractGroup(svg, id) {
  const open = new RegExp(`<g\\b[^>]*\\bid="${id}"[^>]*>`);
  const found = open.exec(svg);
  if (found === null) return null;

  const start = found.index;
  let depth = 1;
  let cursor = start + found[0].length;

  const tag = /<g\b[^>]*?(\/?)>|<\/g\s*>/g;
  tag.lastIndex = cursor;

  for (let m = tag.exec(svg); m !== null; m = tag.exec(svg)) {
    if (m[0].startsWith('</')) {
      depth -= 1;
      if (depth === 0) return svg.slice(start, m.index + m[0].length);
    } else if (m[1] !== '/') {
      // 自己終了(<g ... />)は開いた扱いにしない
      depth += 1;
    }
    cursor = tag.lastIndex;
  }

  return null;
}
```
